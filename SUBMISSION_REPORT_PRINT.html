🔧 Key Engineering Decisions

  • Zero-Hallucination Pipeline: All safety-critical calculations (OPS deadlines, spill volumes, downtime days, cost aggregations) run through deterministic SQLite tools — never LLM text generation.
  • OPS SOP Rev 2 Native: OPS-1 switches gas response deadlines automatically (24h pre-2027 / 12h post-2027); OPS-2 validates every bypass against MOC memo expiry; OPS-5 enforces 7-day heat trace SLAs when ambient ≤ −5°C on producing wells.
  • Dual-Scope Memory: Pump swap reports (Nathan on WELL-0333, Olivia on WELL-0577) propagate to all users via shared memory; sort/format preferences stay private to each operator's session.
  • Generative UI Dispatch: NLU router selects the optimal visual type per question domain — status card, table, SVG line chart, bar, GIS map, or area×month heatmap.
  • Honest Data Gaps: Q1 (reservoir pressure) correctly reports zero pressure telemetry in the dataset rather than fabricating a map.
