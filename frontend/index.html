What the key does: it powers the language layer — natural phrasing of answers and better handling of unusual questions. It can never change a number: every figure, id and citation is computed by the deterministic engine first, and the model is only allowed to rephrase that.
Where the key lives: on this deployment only, in llm_settings.json (gitignored). It is never returned to the browser and never committed. For a permanent Space deployment, the owner can instead set LLM_* environment variables.
